### Hi, I'm Madhav 👋

Computer Science student at VIT Vellore working on systems software for ML inference: quantized SIMD kernels, on-device LLMs, and runtime tuning for local inference engines.

**Selected work**

- **[ondevice-medgemma-arm64](https://github.com/SleezyBear/ondevice-medgemma-arm64)**: MedGemma 4B running fully offline on an Android phone under 4 GiB, with ARMv8.2 DOTPROD quantized kernels and a NEON flash-attention path in llama.cpp, plus a post-training quantization study.
- **[InferenceOS](https://github.com/SleezyBear/InferenceOS)**: an autonomous optimizer for local llama.cpp inference that profiles the hardware, searches GPU offload and per-tensor placement, and keeps a change only after fair A/B measurement.
- **[autonomous-mongodb-optimizer](https://github.com/SleezyBear/autonomous-mongodb-optimizer)**: MongoDB index optimization with sandbox benchmarking, statistical admission, durable PostgreSQL orchestration and ledgered rollback.
